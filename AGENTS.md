# Руководство по проекту

`@zh2s/eslint-config-fsd` — пакет на TypeScript с плоской конфигурацией ESLint 10 для Feature-Sliced Design (FSD). Примеры подключения пакета приведены в [README.md](README.md).

## Язык проекта

Основной язык проекта — русский. Используй его по умолчанию в общении, планах и новой документации. Сохраняй написание идентификаторов, команд и названий инструментов.

## Структура кода

- [src/index.ts](src/index.ts) собирает публичный экспорт по умолчанию с полями `flatConfig`, `rules`, `settings` и `plugins`.
- [src/rules/import-order/index.ts](src/rules/import-order/index.ts) настраивает `import-x/order` для слоёв с числовыми префиксами.
- [src/rules/layers-slices/index.ts](src/rules/layers-slices/index.ts) настраивает допустимые зависимости между слоями через `boundaries/dependencies`.
- [src/rules/public-api/index.ts](src/rules/public-api/index.ts) настраивает разрешённые пути импорта для слайсов и сегментов `shared` через `import-x/no-internal-modules`.
- [src/utils/layers.ts](src/utils/layers.ts) задаёт порядок слоёв от `1-app` до `6-shared`, имена сегментов и шаблоны для каталогов с префиксом `_`.

## Разработка и проверки

- Для сборки используй Node.js 26.13.1, закреплённый в [.nvmrc](.nvmrc) и `devEngines`.
- `npm ci` устанавливает зависимости по `package-lock.json`.
- `npm run build` компилирует TypeScript в `dist/`. `npx tsc --noEmit` проверяет типы без сборки.
- `npx eslint ./src --max-warnings 0` проверяет исходники без исправлений. `npm run fix:all` применяет исправления линтера и форматирование ко всему `src/`.
- При изменении поведения правила проверь разрешённый и запрещённый импорты на небольшом примере с экспортируемой конфигурацией ESLint. Команды `npm test` в проекте пока нет.

## Соглашения

- Используй расширение `.js` в относительных импортах TypeScript. Пакет компилируется в Node ESM с разрешением модулей `NodeNext`.
- Поддерживай оба способа подключения через публичный экспорт пакета — полный пресет и отдельные группы правил. При изменении подключения обновляй примеры в README.
- При правке шаблонов используй общие определения слоёв и сегментов. Проверь затронутые сценарии с группировкой слайсов, сегментами `shared` и каталогами с префиксом `_`.
